1. 실행 방법
 - 압축을 모두 푼 뒤, 같은 폴더 안의 [index.html] 파일을 더블클릭하여
   웹 브라우저(Chrome, Edge, Safari, Firefox 등)로 실행하세요.
 - 별도의 서버나 설치 프로그램 없이 오프라인에서도 즉시 실행됩니다.

2. 조작법
 - 4방향 이동 : 방향키 (↑ ↓ ← →) 또는 W A S D
 - 질주 (달리기) : Shift + 이동키 (스태미나 소모)
 - 전방 조사 / 대화 : E 또는 Space (바라보는 정면 칸 우선 조사)
 - 캐비닛·장롱·기둥 숨기 : H (천장 형광등이 깜빡일 때 즉시 숨으세요!)
 - 도면 미니맵 ON / OFF : M (은신처는 민트색 점으로 표시됩니다)
 - 신경안정제 복용 (정신력 +30) : 1
 - 선택한 단서 2개 증거 조합 : C
 - 수사 수첩 요약 보기 : I

3. 형광등 점멸 & 은신 규칙
 - 평소에는 구역 형광등이 켜져 있어 1998년 은하아파트 내부를 또렷하게
   탐색할 수 있습니다.
 - 원혼이 나타나기 직전에는 천장 형광등이 지지직거리며 8초간 심하게
   깜빡입니다. 불이 완전히 꺼지기 전에 주변 은신처(캐비닛/장롱/기둥)로
   달려가 [H] 키를 눌러 숨으면 위기를 무사히 넘길 수 있습니다.

4. 엔딩 안내 (총 3종)
 - TRUE END  : 단서 9개 이상 수집 + 핵심 진실 조합 + 윤서/인물들과 진실 공유
 - NORMAL END: 단서 5~6개 이상 확보 후 사건 기록 봉인 또는 거울 직면
 - BAD END   : 진실이 불충분한 상태에서 노크 소리에 속아 문을 연다

# 13번째 방문자 (The 13th Visitor) · v1.9.0

**1985년 10월 13일 밤 11시 47분**, 서울 외곽 은하아파트에서 사라진 일가족과 도면에 존재하지 않는 **13층 1304호**의 미스터리를 파헤치는 **16비트 레트로 한국 오컬트 추리 RPG**입니다.

---

## v1.9.0 주요 업데이트 — 캐릭터·포트레이트 도트 리뉴얼 & 시청각 연출 강화

1. **대화창 포트레이트 표정 분기 & 눈 깜빡임 (`js/ui.js`, `js/main.js`)**
   - 강현우·박만식·한미정·윤서·13번째 방문자 포트레이트를 명암과 복장 디테일을 강화한 고밀도 16비트 픽셀 아트로 개편했습니다.
   - 대사 맥락, 화자 유형, 정신력 수치를 분석해 5가지 표정(`normal`, `tense`, `fear`, `sad`, `truth`)이 자동 전환되며 자연스러운 눈 깜빡임 애니메이션이 재생됩니다.
2. **캐릭터 4방향 필드 스프라이트 & 추격자 기괴 연출 (`js/render.js`)**
   - **플레이어(강현우)**: 4방향 보행 프레임, 트렌치코트·라펠·넥타이·머리카락 명암과 팔 스윙 디테일을 강화했습니다.
   - **NPC 3인**: 박만식의 금장 휘장·견장, 한미정의 웨이브 헤어, 윤서의 영체 오라 디테일을 업그레이드했습니다.
   - **13번째 방문자(추격자)**: 불규칙한 프레임 스텝과 고개 꺾임 실루엣, 추격 중 붉은 잔상(afterimage) 트레일 이펙트를 적용했습니다.
3. **바닥 타일·가구 픽셀 아트 & CRT 스캔라인 연출 (`js/render.js`, `index.html`, `style.css`)**
   - 방 테마별 타일 질감·균열·걸레받이 외벽과 가구(차량, 침대, CCTV 듀얼 모니터, 낡은 거울, 서랍장)의 픽셀 디테일을 보강하고 캔버스 CRT 스캔라인·비네트 오버레이를 추가했습니다.
4. **튜토리얼 `다음 ▶` 전체 단계 열람 지원 (`js/main.js`)**
   - 튜토리얼 배너의 `다음 ▶` 버튼만으로도 `1/4 → 2/4 → 3/4 → 4/4` 가이드를 모두 순서대로 확인할 수 있도록 개선했습니다.

## 조작법

- **이동 / 전력 질주**: `WASD` 또는 `방향키(↑↓←→)` / `Shift` 누른 채 이동
- **조사 / 대화 / 대사 스킵 / 숨 참기**: `Space` (프롤로그·회상·타자기 스킵은 `Enter`도 지원)
- **선택지 결정 (대화 / 엔딩)**: 숫자키 `1` ~ `9`
- **은신 진입 / 해제**: `H` (은신 후 추격자 접근 시 `Space` 연타로 숨 참기)
- **수사 수첩 · 단서 조합**: `Tab` (수첩 열기/닫기) / `C` (수첩 열기 또는 선택한 단서 2개 조합)
- **신경안정제 복용 / 미니맵 토글 / 창 닫기**: `Q` / `M` / `ESC`

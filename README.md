# 13번째 방문자 (The 13th Visitor) v1.4.2

1985년 10월 13일 밤 11시 47분, 준공 도면에 존재하지 않는 은하아파트 13층 1304호에서 벌어진 일가족 실종 사건을 파헤치는 한국형 16비트 픽셀 공포 추리 RPG입니다.

## v1.4.2 (Phase 2) 주요 개선 사항
- **추격 밸런스 & 은신 규칙 정비**:
  - `A → B → A` 두 방 왕복만으로 `escapeRoomCount`가 채워지던 추격 해제 꼼수를 차단하고, 서로 다른 구역을 연속으로 이탈해야 추격이 해제되도록 수정했습니다.
  - 정전 추격 중 은신할 때도 숨 참기 미니게임(`[Space]` 연타)이 즉시 발동되도록 일관성을 확보했습니다.
  - 1층 복도, 지하 주차장, 13층 복도, 1304호 안방·아이 방에 은신처를 보강하고, 원혼 추격 속도를 `걷기(4.125칸/초) < 원혼(4.95~5.30칸/초) < 전력 질주(6.75칸/초)`로 정밀 조정했습니다.
  - 정수 인덱스 및 고정 배열 큐 기반 BFS와 타일 변경 시 재계산 캐싱으로 길찾기 성능을 개선했습니다.
- **시간(`dt`) 기반 애니메이션 루프 & HUD 최적화**:
  - 프레임 수(`animTick++`)에 의존하던 형광등 점멸, 원혼 배회 흔들림, 화면 흔들림 감쇠를 `updateVisualTimers(dt)` 기반 초 단위 누적 시간으로 전환해 고주사율 환경의 배속 버그를 해결했습니다.
  - `updateHUD()`에 메모리 캐시와 `dirty-flag`를 적용해 값이 바뀔 때만 DOM과 스토리지 조회를 수행하도록 최적화했습니다.
- **구조 정비 및 접근성·반응형 지원**:
  - 분산된 게임 상수와 매직 넘버를 `js/config.js`로 통합하고, `changeSanity()`와 `isDoor1304Unlocked()`를 단일 진입점으로 정리했습니다.
  - 타이틀 화면에 광과민성 안내 문구와 **점멸 완화(`prefers-reduced-motion`)** 토글을 추가하고, `style.css`에 반응형 `@media` 쿼리를 적용했습니다.

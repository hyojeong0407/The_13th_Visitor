# 13번째 방문자 (The 13th Visitor) — v1.2.0

1985년 10월 13일 밤 11시 47분, 준공 도면에 존재하지 않는 은하아파트 13층 1304호에서 벌어진 일가족 실종 사건을 파헤치는 한국형 16비트 픽셀 공포 추리 RPG입니다.

## v1.2.0 주요 업데이트 내역
1. **프롤로그(4컷 시네마틱) & 4단계 순차 튜토리얼 추가**
   - 새 게임 시작 시 사건의 배경과 주인공 강현우의 사연을 담은 4컷 프롤로그가 재생됩니다. (`Space`/`Enter` 진행, `ESC` 건너뛰기)
   - 프롤로그 종료 후 `이동 → 조사 → 단서 조합 → 조명 점멸 은신/구역 이탈` 4단계 가이드가 순차 진행됩니다.
2. **은신처 축소 및 구역 이탈 추격 밸런스 개편**
   - `1304호 안방`과 `아이 방`의 은신처를 제거하고 전체 은신처를 4곳으로 압축하여, 형광등 점멸(10초 유예) 시 은신처가 없는 방에서는 문을 통해 다른 구역으로 빠르게 이탈하도록 긴장감을 높였습니다.
3. **단서별 연관 단서 조합 힌트 제공**
   - 12종 단서 상세 창 하단에 `연관 단서 힌트`를 명시하여 직관적인 추리 조합이 가능하도록 개선했습니다.
4. **대화 스크립트 핵심 키워드 색상 강조**
   - 날짜/단서명(금색), 인물/장소/조작키(하늘색), 위험/점멸 경고(붉은색), 은신/회복 요소(민트색)를 색상으로 구분해 가독성을 높였습니다.
5. **대화창 16비트 픽셀 캐릭터 포트레이트 일러스트 삽입**
   - 화자(`강현우`, `박만식`, `한미정`, `윤서`, `13층의 원혼`, `수사 기록`)에 맞춰 좌측 상반신 픽셀 일러스트가 실시간으로 전환됩니다.

# 13번째 방문자 (The 13th Visitor) · v1.5.0 (Phase 3)

**1985년 10월 13일 밤 11시 47분**, 서울 외곽 은하아파트에서 사라진 일가족과 도면에 존재하지 않는 **13층 1304호**의 미스터리를 파헤치는 **16비트 레트로 한국 오컬트 추리 RPG**입니다.

---

## v1.5.0 (Phase 3) 주요 업데이트 — 서사 반전 보호 & 추리 코어 루프 고도화

1. **서사 반전 보호 및 이름 복원 연출 (`data.js`, `ui.js`, `main.js`)**
   - 타이틀, 프롤로그, 초반 기록에서 `'1985년 생존 소년 = 강현우'` 스포일러를 제거했습니다.
   - 지하 주차장의 **순찰차 내 수사 메모(`□□□`)**와 숨겨진 방의 **방문자 명부**를 조합해 **[진실 5] 강현우의 잃어버린 기억**을 해금하면, 회상 연출과 함께 훼손된 이름 `[□□□]`가 `[강현우]`로 복원됩니다.
2. **추리 코어 루프 고도화 (`data.js`, `ui.js`, `config.js`, `main.js`)**
   - 모든 단서의 `comboHint`를 짝 단서 직접 표기에서 **질문형 추리 힌트**로 개편하고, 조합으로 진실을 도출하기 전까지 `importance`(핵심 해석)를 비공개로 유지합니다.
   - 수사 수첩(`[Tab]`) 내 **단서 상세 미리보기 카드**를 추가하여 단서 선택 즉시 현장 기록과 추리 질문을 확인할 수 있습니다.
   - **오답 조합 페널티 강화**: 오답 시 누적 정신력 감소(`-8`, 반복 시 `-11`, `-14`... 최대 `-20`)와 함께 점멸 유예 시간 단축(`-3초`) 또는 13번째 방문자의 점멸 경고가 발동합니다.
3. **진실 중심 게이트 · 세계관 일관화 · 보상/도감 동기화 (`state.js`, `main.js`, `ghost.js`)**
   - 단순 단서 소지나 첫 대화만으로 잠긴 문·핵심 증언이 열리던 우회 경로를 제거하고, **수사 수첩에서 도출한 `[진실]`**을 중심으로 1304호 현관문, 벽장 뒤 밀실, NPC 심화 추궁이 열리도록 재설계했습니다.
   - 추격자 명칭과 세계관 설정을 **13번째 방문자**로 일관되게 정비했습니다.
   - **환경 조사 8/8 완료 보상**: 정신력 `+10` 회복과 함께 **정신 내성(정전·추격 근접 정신력 소모 25% 완화)** 및 `TRUE END` 조건 충족 혜택을 부여하며, **엔딩 도감**의 달성 조건 안내를 실제 분기 로직과 100% 동기화했습니다.

## 조작법

- **이동 / 전력 질주**: `WASD` 또는 `방향키(↑↓←→)` / `Shift` 누른 채 이동
- **조사 / 대화**: `E` 또는 `Space` (사물·인물 근처에 돋보기 아이콘 표시 시)
- **은신 / 숨 참기**: `H` (은신처 진입/해제) / 추격자 접근 시 `Space` 연타
- **수사 수첩 · 단서 조합**: `Tab` (수첩 열기/닫기) / `C` (선택한 단서 2개 조합)
- **신경안정제 복용 / 미니맵**: `Q` / `M`

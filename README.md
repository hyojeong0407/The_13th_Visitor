# 13번째 방문자 (The 13th Visitor) · v1.6.0

**1985년 10월 13일 밤 11시 47분**, 서울 외곽 은하아파트에서 사라진 일가족과 도면에 존재하지 않는 **13층 1304호**의 미스터리를 파헤치는 **16비트 레트로 한국 오컬트 추리 RPG**입니다.

---

## v1.6.0 주요 업데이트 — 버그 제로 & 입력·세이브 무결성

1. **엔딩 / 게임오버 키보드 복구 및 입력 안전장치 (`js/main.js`, `js/state.js`)**
   - `DIALOGUE` 및 `ENDED` 모드에서 선택지가 활성화된 경우 숫자키(`1`~`9`)로 즉시 선택할 수 있도록 입력 라우팅을 복구했습니다.
   - 창 포커스 이탈(`blur`) 또는 탭 전환(`visibilitychange`) 시 잔류 키 입력(`clearHeldInputs`)을 초기화해 입력 고착 버그를 방지했습니다.
2. **HTML-Safe 대사 타자기(Typewriter) 연출 및 화자 보이스 블립 (`js/ui.js`, `js/audio.js`, `js/config.js`, `style.css`)**
   - `tokenizeFormattedHtml` / `buildPartialHtml` 기반의 태그·엔티티 안전 타자기 엔진(`startTypewriter`, `finishTypewriter`, `updateTypewriter`)을 도입해 `<span class="hl-*">` 강조가 깨지지 않고 한 글자씩 출력됩니다.
   - 출력 중 `Space` / `Enter` 입력 시 현재 문장을 즉시 완성(스킵)하고, 화자별 고유 톤의 보이스 블립(`playVoiceBlip`)이 재생됩니다.
3. **중첩 대괄호 지원 하이라이트 파서 개편 (`js/ui.js`)**
   - `formatHighlightedDialogue` 정규식을 개편하여 `[[blue:[Space]]]`처럼 내부에 단일 `]`가 포함된 강조 태그도 잘림 없이 정확히 파싱합니다.
4. **세이브 스키마 검증 및 스토리지 폴백 강화 (`js/state.js`, `js/storage.js`, `version.js`)**
   - `js/storage.js`를 신설해 사생활 보호 모드·`iframe`·용량 초과 환경에서도 메모리 폴백(`memoryFallback`)으로 세이브/설정이 동작하도록 보호했습니다.
   - `applyLoadedData`에 유효 ID 화이트리스트 필터링, 레거시 방 이름 마이그레이션(`migrateSaveData`), 좌표 워크어블 보정(`findNearestWalkable`)을 적용했습니다.
   - `version.js` 단일 버전 모듈(`APP_VERSION = "1.6.0"`)을 도입해 타이틀·HTML·세이브 페이로드 버전을 일원화했습니다.
5. **v1.6.0 핫픽스 — 문자열/정규식 이스케이프 구문 오류 수정 (`js/ui.js`, `js/main.js`)**
   - `js/ui.js`의 `formatHighlightedDialogue` 정규식(`/
/g`) 및 `js/main.js`의 다중 행 문자열·내부 큰따옴표(`"`) 이스케이프 11곳을 복구하여 모듈 로드 시 발생하던 `SyntaxError`를 완전히 해결했습니다.

## 조작법

- **이동 / 전력 질주**: `WASD` 또는 `방향키(↑↓←→)` / `Shift` 누른 채 이동
- **조사 / 대화 / 대사 스킵**: `E` 또는 `Space` (프롤로그·회상·타자기 스킵은 `Enter`도 지원)
- **선택지 결정 (대화 / 엔딩)**: 숫자키 `1` ~ `9`
- **은신 / 숨 참기**: `H` (은신처 진입/해제) / 추격자 접근 시 `Space` 연타
- **수사 수첩 · 단서 조합**: `Tab` (수첩 열기/닫기) / `C` (수첩 열기 또는 선택한 단서 2개 조합)
- **신경안정제 복용 / 미니맵 토글 / 창 닫기**: `Q` / `M` / `ESC`

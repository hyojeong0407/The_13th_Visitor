# 《13번째 방문자》 v1.1.1

> **1998년 10월 13일 밤 11시 47분**, 도면에는 12층까지만 존재하는 은하아파트.  
> 13년 전 흔적도 없이 사라진 일가족과 열세 번째 노크 소리의 진실을 파헤치는 **한국형 16비트 픽셀 공포 추리 RPG**입니다.

---

## 1. 실행 방법

1. 배포된 압축 파일을 한 폴더에 모두 압축 해제합니다.
2. 같은 폴더 안에 있는 **`index.html`** 파일을 더블클릭하여 웹 브라우저(Chrome, Edge, Safari, Firefox 등)로 실행합니다.
3. 별도의 웹 서버나 추가 프로그램 설치 없이 **오프라인 환경에서도 즉시 실행**됩니다.

---

## 2. 조작법

| 기능 | 단축키 | 설명 |
| :--- | :--- | :--- |
| **4방향 이동** | `↑` `↓` `←` `→` / `W` `A` `S` `D` | 아파트 복도 및 방 내부 이동 |
| **질주 (달리기)** | `Shift` + 이동키 | 빠르게 이동 (스태미나 소모) |
| **전방 조사 / 대화** | `E` 또는 `Space` | 바라보는 정면 칸의 사물·단서·인물 조사 |
| **은신 (숨기/나오기)** | `H` | 캐비닛·장롱·기둥 근처에서 몸을 숨김 |
| **미니맵 ON / OFF** | `M` | 구역 도면 표시 (은신처는 **민트색 점**으로 표시) |
| **신경안정제 복용** | `1` | 소지한 안정제를 복용해 정신력 **+30** 회복 |
| **증거 조합** | `C` | 수사 수첩에서 선택한 단서 2개를 조합해 진실 도출 |
| **수사 수첩 요약** | `I` | 현재까지 수집한 단서와 핵심 메모 요약 열람 |

---

## 3. 형광등 점멸 & 은신 규칙

* **정상 점등:** 평소에는 구역 형광등이 켜져 있어 1998년 은하아파트 내부를 또렷하게 탐색하고 조사할 수 있습니다.
* **점멸 전조 (8초):** 원혼이 나타나기 직전에는 천장 형광등이 지지직거리며 **8초간** 심하게 깜빡입니다.
* **은신 대처:** 불이 완전히 꺼져 정전되기 전에 미니맵(민트색 점)이나 주변을 확인하여 **캐비닛·장롱·기둥**으로 이동한 뒤 `H` 키를 눌러 숨으세요. 불이 다시 켜질 때까지 숨어 있으면 위기를 무사히 넘길 수 있습니다.

---

## 4. 엔딩 안내 (총 3종)

* **TRUE END — 마지막 방문자와 사라진 가족의 진실**  
  단서 9개 이상 수집 + 핵심 진실 조합 + 윤서 및 관련 인물들과 진실을 공유한 뒤 거울과 직면
* **NORMAL END — 봉인된 미제 사건**  
  단서 5~6개 이상을 확보한 상태에서 사건 기록을 봉인하거나 거울과 직면
* **BAD END — 13번째 방문자**  
  진실이 불충분한 상태에서 문밖의 세 번의 노크 소리에 속아 문을 연다

## 5. 파일 구성

* `index.html` : 게임 메인 화면, 상태창 HUD 및 대화 인터페이스
* `style.css` : 레트로 픽셀 화면, 점멸 전조 배너 및 UI 스타일시트
* `game.js` : 16비트 픽셀 렌더링, Web Audio 사운드, 추리 조합 및 원혼 추격 AI 엔진
* `README.md` : 실행 및 수사 가이드 문서

# 13번째 방문자 (The 13th Visitor) · v1.10.0

**1985년 10월 13일 밤 11시 47분**, 서울 외곽 은하아파트에서 사라진 일가족과 도면에 존재하지 않는 **13층 1304호**의 미스터리를 파헤치는 **16비트 레트로 웹 쯔꾸르 오컬트 추리 RPG**입니다.

---

## v1.10.0 주요 업데이트 — 웹 쯔꾸르 오브젝트 비주얼 전면 개편

1. **맵 위 텍스트 라벨 전면 제거 (`js/render.js`)**
   - 가구(`우편함`, `현관 게시판` 등), 은신처(`숨기[H]`), 문(`경비실`, `지하 주차장`), NPC 머리 위 이름 텍스트를 모두 걷어내 정통 웹 쯔꾸르 화면으로 개편했습니다.
2. **사물별 전용 16비트 픽셀 아트 스프라이트화 (`js/render.js`)**
   - **가구**: 세대별 우편함 칸막이·편지, 압정 메모 게시판·분전함, 듀얼 브라운관 CCTV, 순찰차·폐차, 붉은 소화전, 엘리베이터 `13` 버튼 패널, 소파, 침대, 낡은 거울을 고유 도트로 렌더링합니다.
   - **문 · 계단 · 은신처**: 실내 여닫이문, 지하 주차장 계단 단차, 엘리베이터 이중 슬라이딩 도어, 환기구 슬릿이 있는 철제 캐비닛 및 장롱 은신처를 픽셀 아트로 구분합니다.
   - **현장 소품(`PROPS`) · 아이템 · 미수집 단서**: 벽시계, 인터폰, 경고문, 승강기 검사필증, 쇠사슬 철문, 다이얼 전화기, 달력, 봉제 인형, 구급 약병(`+`)을 실물 도트로 표시하고 미수집 단서에는 반짝임(Glint) 효과를 추가했습니다.
3. **쯔꾸르식 말풍선 포커스 & 암전 맵 전환 (`js/render.js`, `js/movement.js`, `js/state.js`)**
   - 상호작용 대상 근처에 다가가면 `···` / `!` / 이동 화살표 / 은신 픽셀 말풍선이 떠오르며, 문·엘리베이터 이동 시 부드러운 암전 페이드 전환이 재생됩니다.

## 조작법

- **이동 / 전력 질주**: `WASD` 또는 `방향키(↑↓←→)` / `Shift` 누른 채 이동
- **조사 / 대화 / 대사 스킵 / 숨 참기**: `Space` (프롤로그·회상·타자기 스킵은 `Enter`도 지원)
- **선택지 결정 (대화 / 엔딩)**: 숫자키 `1` ~ `9`
- **은신 진입 / 해제**: `H` (은신 후 추격자 접근 시 `Space` 연타로 숨 참기)
- **수사 수첩 · 단서 조합**: `Tab` (수첩 열기/닫기) / `C` (수첩 열기 또는 선택한 단서 2개 조합)
- **신경안정제 복용 / 미니맵 토글 / 창 닫기**: `Q` / `M` / `ESC`

# 13번째 방문자 (The 13th Visitor) v1.4.0

1985년 10월 13일 밤 11시 47분, 준공 도면에 존재하지 않는 은하아파트 13층 1304호에서 벌어진 일가족 실종 사건을 파헤치는 한국형 16비트 픽셀 공포 추리 RPG입니다.

## v1.4.0 (P1) 주요 개선 사항
- **ES 모듈 아키텍처 & 상태 머신 리팩터링**: `js/data.js`, `js/state.js`, `js/audio.js`, `js/ghost.js`, `js/render.js`, `js/ui.js`, `js/main.js` 7개 ES 모듈로 분리하고, `GAME_MODE`(TITLE/PROLOGUE/PLAY/DIALOGUE/FLASHBACK/ENDED)와 `GHOST_STATE`(IDLE/WARNING/CHASE/SEARCH) 상태 머신을 적용했습니다.
- **탐색 몰입 강화 (`[!]` 표식 제거 & 돋보기 표시)**: 맵과 미니맵에서 단서 위치 표시를 제거하고, 조사 가능한 대상에 인접했을 때만 돋보기 아이콘이 표시됩니다.
- **은신 발각 및 숨 참기 미니게임**: 추격자가 은신처 근처를 수색할 때 `[Space]` 키를 연타해 숨을 참아야 하며, 같은 은신처를 반복 사용할수록 숨 참기 난이도가 상승합니다.
- **정신력 단계별 화면 효과**: 정신력에 따라 시야 반경이 축소되고, 40 이하에서는 가짜 단서 환각과 환청이, 20 이하에서는 미니맵 좌표 왜곡이 발생합니다.
- **캔버스 중심 UI & Tab 메뉴 수납**: 캔버스 뷰포트를 확대(`min-height: 540px`, `image-rendering: pixelated`)하고 대사창을 하단 오버레이로 배치했으며, 수사 수첩·소지품·로그는 `Tab` 키로 여닫는 슬라이드 드로어로 수납했습니다.
- **경비원 박만식 3단계 자백**: 증거 1개 제시(부인) → `[진실 2]` 제시(방화문 봉쇄 인정) → 방문자 명부/과거 기억 제시(완전 자백)로 이어지는 3단계 자백 구조를 적용했습니다.
